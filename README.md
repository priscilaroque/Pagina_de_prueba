# Priscila Roque — deMok2

Sitio personal para aprender, explorar y compartir recursos sobre el uso del software deMok2.

## Desarrollo
- HTML, CSS y JavaScript nativo (sin dependencias).
- Diseño adaptable a móviles y escritorio.
- Fondo abstracto psicodélico con estética elegante.
- Publicación prevista en Vercel.

## Ejecutar localmente
Abre `index.html` en tu navegador.

## Personalización
Los apartados de tutoriales y herramientas están preparados como estructura inicial. El contenido específico de deMok2 puede ampliarse conforme se definan los módulos y funciones que se desean explicar.
